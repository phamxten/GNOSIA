# GNOSIA — UI States (PRD §15, adapted to the 4-phase concept)

For each state: **where** it appears, the **copy** (Bahasa Indonesia, final), the **visual**, and the **behaviour**. "See" points to a mockup where the state can be triggered (usually via the top-right mockup state switcher or `?state=`).
